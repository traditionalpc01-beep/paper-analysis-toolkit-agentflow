# Utils Directory Guide

- `config.py`：运行时配置加载、默认值、配置路径
- `config_crypto.py`：配置敏感字段的本地加解密
- `config_wizard.py`：交互式配置向导
- `env_checker.py`：运行环境检查
- `file_renamer.py`：输出后文件重命名辅助
- `hash_utils.py`：哈希与指纹工具
- `journal_metadata.py`：期刊标题规范化与元数据辅助
- `logger.py`：日志与错误记录
- `pdf_utils.py`：PDF 文件辅助方法
- `terminal.py`：终端展示辅助

Agent 遇到通用工具、配置辅助、日志能力、文件命名或期刊名称规范化问题时，先从本目录查找。
